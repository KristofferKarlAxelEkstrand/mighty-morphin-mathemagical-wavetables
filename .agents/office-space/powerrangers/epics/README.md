# Epics

Larger bodies of work that do not fit in a single task. Break an epic down into individual tasks
filed under `../tasks/todo/` once its scope is settled.

- `drafts/` — epics still being scoped; not yet ready to break into tasks
- `todo/` — epics ready to break down into tasks

There is no separate "done" stage for epics — once every task it spawned is done, the epic is done.
If it is worth keeping as a durable record of what shipped and why, note that in
`../records/decisions/` and delete the epic file.
