# Generator audio contract

This spec is the review bar for every registered wavetable generator. Quality rejects work that
breaks it. Implementers load skill `wavetable-generator` for the procedure.

## Scope

Applies to classes under `maths/` that extend `BaseGenerator` and register with
`@register_generator`. The public method is `generate(theta, u)`.

Out of scope unless a task names a human gate: changing this signature, `ProcessingConfig`, or
adding a runtime dependency.

## Parameters

- `theta` is a 1-D `float64` array for one cycle. Values run from `0` to `2π` (use
  `endpoint=False` when building it). Units are radians, not degrees.
- `u` is a Python `float` in `[0.0, 1.0]`. It is the morph amount.
- `generate` must call `_validate_u(u)` and raise `ValueError` when `u` is outside that range.

## Raw `generate()` output

The array returned by `generate` must:

1. Have dtype `float64`
2. Have the same length as `theta`
3. Contain only finite values (no NaN, no Inf)
4. Not be all zeros
5. Come from a mathematical formula. Do not load a WAV or other sample as the waveform source.

Peak and DC on the raw array may be imperfect. The processing pipeline (`get_processing()` flags)
normalizes and removes DC after `generate`.

## After the processing pipeline

When `generate_wavetable` (or the equivalent CLI path) runs with the generator's `get_processing()`
flags, each frame must:

1. Have peak absolute value in `[0.95, 1.05]`
2. Have mean (DC) with absolute value `< 0.01`
3. Stay finite

Loop wrap: the first-to-last step must match the formula. A sine or triangle stays nearly
continuous at the wrap. A saw or square may have one intended jump. Random extra discontinuities
are a defect.

## Tests

Tests that claim the contract apply to generators must parametrize over **all** names in
`get_registry()`, not only the first entry (`any_generator`).

A test that calls `generate` with `u` outside `[0, 1]` must expect `ValueError`.

## Readability

Generator code is teaching material. Prefer a short named formula over compressed NumPy. Review
may reject a correct but opaque implementation.
